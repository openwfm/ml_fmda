# Associated Publications

The project repo is tagged with `orig2026` to mark the project state for replication of the following papers. Subsequentcoding development does not change the scientific content of this project state, but introduces coding advances and other changes that break exact reproducibility.

## Main Model Description and Forecast Accuracy Experimental Design

Title: *A Recurrent Neural Network for Forecasting Dead Fuel Moisture Content with Inputs from Numerical Weather Models*

This paper includes description on data collection, model architecture, hyperparameter tuning, training procedure, validation design, forecast accuracy results from the Rocky Mountain region in 2024.

https://doi.org/10.3390/fire9010026

Suggested citation: 

J. Hirschi, J. Mandel, K. Hilburn, and A. Farguell. A recurrent neural network
for forecasting dead fuel moisture content with inputs from numerical weather
models. Fire, 9(1), 2026. ISSN 2571-6255. doi: 10.3390/fire9010026. URL
https://www.mdpi.com/2571-6255/9/1/26.

## PhD Thesis 

Title: *Time-warping Recurrent Neural Networks for Transfer Learning*

Develops a method for time-warping a pretrained LSTM. Mathematical proofs under strong assumptions, then an empirical case with predicting fuel moisture content for different fuel classes. PhD Thesis in Applied Mathematics from CU Denver.
